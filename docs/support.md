# Support

Use GitHub issues for reproducible bugs and focused feature requests. Include
`whoop --version`, operating system/architecture, installation method, command,
and redacted output. Never include client secrets, refresh tokens, access
tokens, or private WHOOP records.

Use the private GitHub Security advisory flow for vulnerabilities; see
[`SECURITY.md`](../SECURITY.md). Questions about WHOOP API availability,
scopes, rate limits, or undocumented behavior should also include a link to
the relevant official WHOOP documentation.

The project is maintained on a best-effort basis. Releases support the latest
published version and the default branch; upgrade before investigating an old
release.
